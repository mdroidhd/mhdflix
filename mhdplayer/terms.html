📄 Términos y Condiciones de Uso

Última actualización: 18 de octubre de 2025

Bienvenido/a a Mhdplayer, una aplicación desarrollada por Leonardo Alexander Soto. Al descargar o utilizar esta aplicación, aceptas los siguientes Términos y Condiciones.

Por favor, léelos detenidamente antes de usar la aplicación.

1. Aceptación de los términos

El uso de Mhdplayer implica la aceptación completa de estos Términos y Condiciones.

Si no estás de acuerdo con alguna parte de los mismos, debes abstenerte de usar la aplicación.

2. Descripción del servicio

Mhdplayer es una aplicación móvil diseñada para reproducir contenido multimedia almacenado localmente en el dispositivo del usuario, ofreciendo una experiencia fluida y sin necesidad de conexión a internet para la reproducción.

La aplicación puede incluir servicios adicionales como:

  • Recomendaciones o contenido promocional.
  • Publicidad mostrada mediante el servicio de terceros Wortise.

3. Permisos requeridos

La aplicación puede solicitar ciertos permisos del sistema para funcionar correctamente:

  • Acceso a archivos multimedia: utilizado únicamente para explorar y reproducir videos o música almacenados en el dispositivo.
  • Acceso a internet: necesario para mostrar anuncios o verificar actualizaciones.

Mhdplayer no recopila, almacena ni transmite archivos personales ni multimedia del usuario.

4. Publicidad

Mhdplayer utiliza el servicio publicitario de Wortise, el cual puede recopilar identificadores no personales (como el ID de publicidad de Google) para mostrar anuncios relevantes o no personalizados.

El uso de la aplicación implica la aceptación de que se muestren anuncios dentro de ella. Puedes consultar más información sobre el tratamiento de datos publicitarios en:

🔗 https://www.wortise.com/privacy-policy
